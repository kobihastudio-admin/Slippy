# Slippy LINE Rich Menu Tools

Standalone rich-menu configuration and upload helper. Run from this directory with `node upload-rich-menu.js` after providing `LINE_CHANNEL_ACCESS_TOKEN` and the required `slippy-rich-menu.png` image. Running the helper changes the connected LINE account, so verify the target account first.

For the application-managed rich menu use `npm run setup:richmenu --workspace=api` from the repository root.
