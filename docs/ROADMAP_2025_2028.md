# Roadmap

Status: **derived from code, git history and `BUSINESS_MODEL.md`**, as of 2026-10-12. The repository contains **no dated plan**: `BUSINESS_MODEL.md` lists six phases without dates, owners or scope, and nothing in the code, issues or docs assigns a year to them. The file name's "2025–2028" is therefore not backed by any source here; this document does not invent dates. It records the stated phases, how far each is built, and what the repository shows about recent pace. Where this document and the code disagree, the code is right.

## Stated phases (`BUSINESS_MODEL.md`, "Long-Term Goal")
| # | Phase (owner's wording) | Built today | Evidence |
|---|---|---|---|
| 1 | AI Receipt Platform | **Yes, the most complete part** | OCR pipeline with validation and fallback, review/approval, web + LINE + email intake — OCR_ENGINE_SPEC.md |
| 2 | AI Financial Assistant | **Partly** | VAT/WHT reports, claims and budgets, accounting connectors; the assistant answers questions but is a single prompt, not a financial advisor — AI_ASSISTANT_SPEC.md, BUSINESS_SUITE_SPEC.md |
| 3 | Life Graph Platform | **Partly** | schema, population from approved documents, scores, Activity Graph; the two life-score implementations disagree — LIFE_GRAPH_SPEC.md |
| 4 | AI Life Assistant | **Early** | chat with memory and Life Graph context; the LINE "Nova" entry is a canned message — AI_MEMORY_SPEC.md, AI_ASSISTANT_SPEC.md |
| 5 | Creator Economy | **Schema only** | products and affiliate links can be created, but there is no redirect, tracking, attribution or payout — CREATOR_ECONOMY_SPEC.md |
| 6 | Life Operating System (Wealth, Lifestyle, Journey, Social, Business) | **Breadth exists, integration does not** | trips, split bills, sport, health and social features are built; they share a user and LINE identity but not a domain model — DOMAIN_DRIVEN_DESIGN.md |

Work has clearly gone beyond phase 1 into 3–6 (trips, health, sport, social) while phases 2, 4 and 5 are still thin; that is a sequencing fact, not a judgement.
