# 08 UI / UX Flow

## 1. iOS Main Screens

```text
Login
→ Player Setup
→ Home Dashboard
→ Start Session Guide
→ Live Session Mirror
→ Session Summary
→ History
→ Profile
```

## 2. watchOS Screens

```text
Watch Home
→ Start Badminton
→ Live Tracking
→ Pause / Resume
→ End Session
→ Mini Summary
```

## 3. iOS Home Dashboard

Show:

- Last session summary
- Weekly total shots
- Weekly smash count
- Active minutes
- Skill score
- Button: Start on Apple Watch

## 4. Watch Live Tracking Screen

Show large numbers:

```text
Time       24:15
Shots      186
Smash       32
HR         148
```

Buttons:

- Pause
- End

## 5. Session Summary Screen

Sections:

1. Hero summary
2. Shot statistics
3. Heart rate / calories
4. AI Coach insight
5. Share to LINE

## 7. Design Direction

- Use Slippy green theme
- Friendly, sporty, clean UI
- Large typography on Watch
- Minimal watch interactions
- Thai-first, English later
